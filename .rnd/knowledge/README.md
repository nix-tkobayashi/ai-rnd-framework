# knowledge/

- `shared/` - validated, reusable workspace knowledge (promoted from cases; frontmatter: title, tags, sourceCases, evidence, freshnessClass, lastVerified, status, promotedAt)
- `candidates/` - promotion candidates awaiting independent review
- `catalog.json` - generated by `scripts/generate_index.py`; do not edit

Lookup priority for agents: **case knowledge > shared knowledge > agent memory**. Entries past their freshness window (fast-moving 30d, normal 180d, stable 365d) must be re-verified before use. See the `knowledge-promotion` skill.
